# SolidityPivot

Translates and compiles Solidity smart contract code into multiple programming languages for development and testing purposes.

With SolidityPivot, you get a lightweight tool that stays out of your way.

**What you get**

- Translates and compiles Solidity smart
- contract code into multiple programming
- languages for development and testing

## Key Features

- Translates and compiles Solidity smart
- contract code into multiple programming
- languages for development and testing

## Technology Stack

- javascript
- Standard library, minimal dependencies
- unittest/pytest

## Installation

1. Clone the repository: `git clone https://github.com/vishalrankhamb/SolidityPivot.git`
2. Install dependencies: `pip install -r requirements.txt`
3. Run the test suite: `pytest`

## Configuration

SolidityPivot is configured through environment variables (see `.env.example`). Key options:
- **APP_ENV**: `development` or `production`.
- **PORT**: Port the server listens on.
- **LOG_LEVEL**: `debug`, `info`, or `error`.
